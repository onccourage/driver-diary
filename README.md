# Дневник смен водителя

Мини-проект: сервер (HTTP API) + консольный клиент. Python 3.9+, **без внешних зависимостей**.

## Запуск
```bash
python server.py            # сервер на :8000, данные в data/trips.json
python client.py            # консольный клиент (в другом терминале)
python -m unittest discover -s tests -v   # тесты
```
Клиент: `n` — следующий день, `p` — предыдущий, `d 2026-10-01` — выбрать дату, `a` — добавить поездку, `q` — выход.
В примере данных поездки за **2026-10-01**.

## API
- `GET /api/trips?date=YYYY-MM-DD` → `{date, summary, trips}`
  summary: `trips`, `revenue`, `commission`, `on_hand`, `cash{trips,amount}`, `card{trips,amount}`
- `POST /api/trips` → `201` создана, `200` дубль (ничего не создано), `422` ошибка данных,
  `409` тот же `id`, но другие данные, `400` невалидный JSON.

## Решения и допущения
- «На руки» = выручка − комиссия (наличные/карта показаны отдельно).
- День поездки — по дате начала в часовом поясе самой поездки.
- Валидация: `amount > 0`, `end > start`, часовой пояс обязателен, `payment ∈ {cash, card}`, `0 ≤ commission ≤ amount`.
- Защита от дублей: по `id`; если `id` не передан — генерируется из содержимого (повтор даст тот же id);
  то же содержимое под другим `id` тоже считается дублем.
- Хранилище — JSON-файл, запись под блокировкой.
